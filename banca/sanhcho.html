CẤU TRÚC THƯ MỤC & ĐỒNG BỘ VÍ XU

📋 Cách liên kết Sảnh Chờ • Bắn Cá • Đỏ Đen

📁 1. Đặt 3 file trong cùng 1 thư mục máy tính:
  • index.html — File Sảnh Chờ Siêu Thị Giải Trí (File hiện tại).
  • banca.html — File Game Bắn Cá Siêu Thị 2D.
  • doden.html — File Game Đấu Trường Đỏ Đen (bước tiếp theo mình sẽ tạo cho bạn).
🔗 2. Cơ chế đồng bộ tự động qua khóa ARCADE_WALLET_COINS: 
// Đọc số dư xu từ Ví Chung (Mặc định 2500 Xu)
let score = parseInt(localStorage.getItem('ARCADE_WALLET_COINS') ?? '2500', 10);

// Hàm lưu xu mỗi khi bắn cá hoặc đặt cược Đỏ Đen
function syncWalletCoins(newScore) {
    score = Math.max(0, Math.floor(newScore));
    localStorage.setItem('ARCADE_WALLET_COINS', String(score));
}
